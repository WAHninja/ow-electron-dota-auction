Database Configuration

We use Supabase to store match data, player stats, and auction history.

Don't have Supabase?
  1. Go to supabase.com
  2. Create a free account and new project
  3. Run the SQL schema (see documentation)
  4. Get your credentials from Settings → API
⚠️ Important: Use SERVICE ROLE Key
This app requires the service_role key (not the anon key) to bypass Row Level Security. Find it in: Settings → API → Project API keys → service_role (secret)
Found in Settings → API → Project URL
⚠️ Use service_role key (NOT anon key) from Settings → API → service_role
